# IdeaOps

Ideas deserve version control.

IdeaOps is an open methodology for developing ideas with AI using Git, Markdown, and autonomous agents.

Instead of treating conversations as disposable, IdeaOps turns them into reproducible artifacts.

---

## Principles

- Every good idea deserves a commit.
- Markdown is the source of truth.
- AI agents have roles.
- Git remembers evolution.
- Conversations produce artifacts.

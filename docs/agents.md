Agents

IdeaOps treats AI systems as specialized team members rather than interchangeable assistants.

Each agent has a clearly defined responsibility.

---

Human

Role: Vision, taste, and final decisions.

Responsibilities:

- Define goals.
- Evaluate ideas.
- Make creative decisions.
- Approve releases.

---

ChatGPT

Role: Research & Creative Architect.

Responsibilities:

- Brainstorm concepts.
- Write and refine documents.
- Design project architecture.
- Build worldbuilding.
- Develop lyrics and narratives.
- Connect ideas across projects.

---

Codex

Role: Software & Repository Engineer.

Responsibilities:

- Maintain repository structure.
- Refactor documents.
- Generate and modify project files.
- Automate repetitive tasks.
- Manage commits and pull requests.
- Assist with implementation.

---

GitHub

Role: Long-term memory.

Responsibilities:

- Preserve project history.
- Track idea evolution.
- Store released artifacts.
- Enable collaboration.

---

Suno

Role: Music generation engine.

Responsibilities:

- Transform lyrics into songs.
- Explore musical directions.
- Produce candidate tracks.

---

Future Agents

IdeaOps is intentionally extensible.

New agents should be added when they bring a clearly defined responsibility rather than duplicating an existing role.
